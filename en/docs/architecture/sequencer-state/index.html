Sequencer & State Management

Polyrhythmic clock engine, sub-block sample-accurate event scheduling, and full project persistence.

The sequencer engine (Source/Sequencer/SequencerEngine.{h,cpp}) drives step triggering and playhead animations. It provides clock-tight synchronization while enabling complete metric independence across the 6 lanes.

Clock Engine Architecture

The timing grid is governed by the global tempo parameter (BPM):

Each step corresponds to a sixteenth note (1/16th note division).

6-Lane Polyrhythmic Independence

Unlike traditional synthesizers where a single master counter resets all tracks, each sequence s tracks its own fractional sample phase and its own loop length L_s between 1 and 32 steps:

Patterns slip and intertwine, generating evolving polyrhythms with zero sample drift.

Sub-Block Event Slicing (process)

To eliminate timing jitter caused by variable audio host buffer sizes (e.g., 256, 512, or 1024 samples), the engine slices each audio buffer at exact sample boundaries:

When a step boundary is crossed:

  1. A gateOff event releases the prior active note.
  2. If the active step is enabled in the sequence bitmask ((mask & (1 << step)) != 0), a gateOn event is queued with its exact intra-buffer sample offset.
  3. Voice::renderSegment() renders audio slices between successive event offsets.

Plugin State Serialization

Metulifer persists complete plugin state during DAW project saves or preset archiving via getStateInformation() and restores it via setStateInformation().

Architectural Benefits of Tree Segregation

  1. Clean DAW Automation: 192 step toggles and dynamic patch cables do not pollute DAW automation tracks.
  2. Binary Performance: The XML tree is serialized to compressed binary with juce::copyXmlToBinary for zero-overhead disk I/O.
  3. Backward Compatibility: New schema nodes can be introduced safely without breaking older session files.
