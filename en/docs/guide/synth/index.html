Synth

Two VCOs, two ADSRs, dB mix and gain staging — the synth dedicated to each sequence.

One synth per sequence

Every sequence owns its own Voice instance (Source/DSP/Voice). Important consequence: a sequence is monophonic — it plays one note at a time. The plugin can therefore produce up to 6 simultaneous notes, one per sequence.

The two VCOs

ParameterIDsRangeDefault
OctaveseqN_octave1, seqN_octave2−2 … +2 (lever, 5 positions)0
NoteseqN_note1, seqN_note20 … 11 (C … B)0 (C)
WaveformseqN_wave1, seqN_wave2Sine / Saw / Square / TriangleSaw

Frequency is computed from C3 = 130.81 Hz:

Examples: octave 0, note 0 → 130.81 Hz (C3) · octave +1, note 7 → 392.00 Hz (G4).

Anti-aliasing

Saw and Square use polyBLEP: transitions are smoothed to strongly reduce spectral aliasing, without wavetables. Sine and Triangle are computed directly (no discontinuity).

The octave lever

The vertical lever (Source/UI/Lever) has 5 positions: +2, +1, 0, −1, −2. It is bound to seqN_octaveN through a ParameterAttachment, so it is:

  • automatable by the DAW;
  • undoable;
  • saved with the plugin state.

The Note knob

12 positions, from C to B. Combined with the lever, it spans 5 octaves × 12 semitones. No MIDI input yet: pitch comes only from these two controls.

The two ADSRs

One ADSR per VCO: VCO1 → ADSR1, VCO2 → ADSR2.

ParameterIDsRangeDefault

Each active step triggers noteOn() on the voice; an inactive step triggers noteOff(). The release tail keeps ringing after the step, which gives the natural legato between close steps.

Mix and gain staging

ParameterIDsRangeDefault
Mix VCO1seqN_mix1−60 … +6 dB0 dB
Mix VCO2seqN_mix2−60 … +6 dB0 dB
VolumeseqN_volume0 – 100 %80 %

Three safeguards prevent clipping:

  1. Normalised sum: (VCO1 × mix1 + VCO2 × mix2) × 0.5 → two oscillators at 0 dB sum to 0 dBFS, not +6 dBFS.
  2. Hard mute: mix <= −59 dB ⇒ gain exactly 0.0.
  3. Volume at 0: the voice mutes its output and resets the reverb (true silence).

Finally, processBlock applies a global ×0.5 headroom and a soft tanh() saturation, guaranteeing an analogue-style ceiling without hard converter clipping.

Output level

If the signal still clips in your DAW, lower seqN_volume first, then the mix values, instead of compensating on the host master.

Sequencer

Six independent 32-step sequences, polyrhythm, length, volume, copy/paste and playhead.

Filter (VCF)

Low-pass or high-pass TPT filter, cutoff 20 Hz – 20 kHz, per sequence.
