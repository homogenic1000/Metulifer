Multi-FX (Reverb, Delay, Redux)

3-in-1 effects processor per sequence with tabs, LED status indicators, and serialized DSP processing.

The Multi-FX panel (located at the right edge of the interface) provides three independent audio processors for each sequence:

  1. Stereo Reverb (Room / Hall acoustic space emulation)
  2. Ping-Pong Delay (Stereo echo line with analog-modeled soft saturation)
  3. Redux (Bitcrusher and sample-rate decimation engine)

Each effect can be engaged or bypassed independently, with full per-sequence parameter isolation.

Tab Navigation & Activity LEDs

To combine ergonomic space efficiency (105 × 224 pixels) with immediate control, the panel uses three tabs:

  • [REV]: Reverb parameters
  • [DLY]: Delay parameters
  • [RDX]: Redux parameters

Each tab button hosts an integrated LED indicator (green / cyan) that shows real-time active status for that effect on the selected sequence, regardless of which tab is currently displayed.

1. Reverb Tab (REV)

Produces spatial acoustics using an optimized Freeverb stereo engine.

Mode Profiles

  • Room: Room size 0.45, damping 0.55, width 0.80. Adds air and acoustic glue without muddying fast transients.
  • Hall: Room size 0.85, damping 0.25, width 1.00. Deep, expansive decay tails for lush pads and ambient leads.

2. Delay Tab (DLY)

Full-featured stereo delay with warm tanh feedback saturation and stereo ping-pong bounce.

Analog-Style Feedback Saturation

The delay feedback path incorporates a hyperbolic tangent (tanh) transfer curve: pushing feedback to high percentages produces rich harmonic density without unpleasant digital harshness.

3. Redux Tab (RDX)

The Redux processor recreates vintage digital grit and early digital sampler character (8-bit and 12-bit eras).

Creative Recipes

  • Chiptune / Lo-Fi 8-bit: Bits = 8, Rate = 4 or 8.
  • Digital Fuzz Stabs: Bits = 2 or 3, Rate = 1, Mix = 70%.
  • Subtle Modern Crunch: Bits = 12, Rate = 2, Mix = 30%.

Patch Cable LFO Modulation

All Multi-FX knobs are fully modulatable via virtual patch cables:

  • Modulate delay time (seqN_delay_time) for organic tape-warble, chorus, or pitch sweeps.
  • Modulate feedback (seqN_delay_feedback) for rhythmic swelling textures.
  • Modulate sample rate decimation (seqN_redux_rate) for cutting sweeps.
  • Modulate reverb mix (seqN_reverb_mix) for dynamic breathing tails.

Filter (VCF)

Low-pass or high-pass TPT filter, cutoff 20 Hz – 20 kHz, per sequence.

Melodic Arpeggiator

11 algorithmic modes, 10 chords & scales, up to 3-octave span, and sample-accurate step-gated triggers.
