**Metulifer** is a digital step sequencer built with JUCE for the **Saumure** brand.
It packs **six independent programmable sequences**, each with **its own synth**:
two VCOs, two ADSRs, a VCF filter, a 3-in-1 Multi-FX unit (Reverb, Delay, Redux), an 11-mode arpeggiator, and two patchable LFOs.

## What the plugin does

| Block | Role |
|---|---|
| **Sequencer** | 6 sequences of up to 32 steps, with independent length and tempo per sequence (polyrhythm) |
| **Synth** | Per sequence: 2 VCOs (sine / saw / square / triangle), 2 ADSRs, mix in dB |
| **Arpeggiator** | 11 algorithmic modes (Up, Down, Pinky Up...), 10 scales/chords, 1 to 3 octave span |
| **VCF** | Low-pass or high-pass TPT filter, cutoff 20 Hz – 20 kHz |
| **Multi-FX** | 3-in-1 FX unit per sequence: Stereo Reverb (Room/Hall), Tanh saturated ping-pong Delay, and Redux Bitcrusher |
| **Modulation** | 2 LFOs (rate, shape, offset, depth) wired to knobs with virtual patch cables |
| **Display** | Visual feedback: selected sequence, touched parameter, output RMS level |
| **Inspector** | Built-in Melatonin visual component inspector (`⌘I` or Inspect button) |

## Where to start

<Steps>
  <Step>
    ### Install the requirements

    JUCE, Xcode and Projucer. See [Installation](/en/docs/getting-started/installation).
  </Step>
  <Step>
    ### Build the plugin

    `Projucer --resave` then `xcodebuild` (or Xcode). The **Standalone** target is enough to test.
  </Step>
  <Step>
    ### Make a sequence sing

    Toggle a few steps on a row, hit **Play**. See [First sound](/en/docs/getting-started/quick-start).
  </Step>
</Steps>

## Documentation conventions

- File paths are relative to the repository root.
- `Source/` is the only code folder to edit; `Builds/` and `JuceLibraryCode/` are generated by Projucer.
- Parameter IDs are written in `code`: `seq1_cutoff`, `lfo2_depth`, `tempo`…
