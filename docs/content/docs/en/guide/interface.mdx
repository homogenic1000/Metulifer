## UI map

The editor is **1280 × 720** and places its panels at absolute coordinates
(`resized()` in `Source/PluginEditor.cpp`).

| Panel | Position (x, y) | Size |
|---|---|---|
| Sequencer (6 rows with ARP toggles) | 32, 32 | 910 × 417 |
| OLED display | 986, 32 | 247 × 132 |
| CLOCK | 961, 164 | 297 × 284 |
| Synth (2 VCO, 2 ADSR, Mix, ARP controls) | 32, 458 | 786 × 237 |
| VCF (LPF/HPF filter) | 684, 471 | 105 × 224 |
| LFO 1 | 874, 471 | 105 × 224 |
| LFO 2 | 1013, 471 | 105 × 224 |
| Multi-FX (Tabs: REV, DLY, RDX) | 1144, 471 | 105 × 224 |

The `CableLayer` covers the whole window (0, 0, 1280, 720) but its `hitTest()` only
returns `true` near a jack or a cable: clicks pass through everywhere else.

## The OLED Display & Studio Monitoring

The central display is synchronized at **60 Hz** with zero perceived latency:

### 1. Phase-Locked Real-Time Oscilloscope
When parameters are untouched, the screen renders an ultra-precise oscilloscope trace:
- **Rising Zero-Crossing Trigger**: Automatic trigger detection locks waveform phase in place, keeping the waveform steady with zero jitter or drift.
- **Dynamic Period Scaling**: Measures fundamental frequency to always display exactly **2 full waveform cycles**, regardless of the pitch played.
- **Adaptive Auto-Gain**: Fits vertical amplitude to occupy ~82% of screen height with a soft decay to flat line during silence.
- **Measurement Graticule**: Subtle vector grid lines at 25%, 50%, and 75% height.

### 2. Studio Stereo dBFS Meter
Below the oscilloscope is a calibrated professional stereo dBFS meter:
- **Independent L and R channels**: Dual bargraphs reading from -48 dBFS to +3 dBFS.
- **Instant Attack & Logarithmic Fallback**: Zero-latency peak capture with natural 54 dB/s logarithmic decay.
- **1-Second Peak Hold**: Retains maximum transient peaks for 1 second before decaying.
- **CLIP Indicator**: High-contrast red alert when exceeding 0 dBFS.
- **Tenth-of-a-dB Readout**: Real-time numerical display (e.g. `-6.2 dB` or `-inf dB`).

### 3. Contextual Parameter Display
Whenever a knob or button is adjusted, the screen shifts immediately into amber **EDIT** mode for 2 seconds:
- Displays full parameter name, exact value, and unit (e.g. `seq 1 cutoff 1250 Hz`, `tempo 128.0 BPM`, `reverb Room`).
- Shows sequencer feedback alerts (e.g. `SEQ 1 COPIED`, `SEQ 2 PASTED`).

## CLOCK Panel & Transport Control

Positioned below the OLED screen, the **CLOCK** panel (961, 164) houses the master timing controls:

- **Tempo Rotary Knob**: Adjusts playback speed from 20.0 to 300.0 BPM.
- **Play/Stop Button**: Manually triggers or pauses sequencer playback in free-running mode.
- **Sync Toggle Button**: Engages real-time synchronization with the host Digital Audio Workstation (DAW). When active, tempo and transport tracking are slaved to the DAW timeline.

## Live LFO Modulation Feedback

Metulifer features a complete real-time visual feedback loop between LFO modulators and target synth knobs:

1. **LFO OLED Mini-Screens**:
   - Each LFO slice has a backlit OLED screen displaying the exact connected parameter target (e.g. `SEQ 1 CUTOFF`, `SEQ 3 DLY TIME`) or `[ UNLINKED ]`.
   - Real-time display of active waveform (`SIN`, `SAW`, `SQR`, `TRI`) and modulation frequency in Hertz (e.g. `3.5Hz`).
   - Pulsing activity indicator and LED brightness ring next to the output jack.
2. **Real-Time Modulated Knobs**:
   - Any knob modulated by an active LFO displays a dynamic **two-tone modulation arc** (amber for LFO 1, cyan for LFO 2) indicating real-time swing.
   - The knob's needle actively rotates in sync with the LFO wave.
   - A reference indicator dot marks the user's static base setting.

## Pagination by selection

A single set of knobs serves all six sequences:

- clicking a row calls `bindSequence(index)`;
- the synth, arpeggiator, VCF and Multi-FX `SliderAttachment`s are **destroyed and recreated** on the
  `seqN_*` parameters of the chosen sequence;
- an `updatingBindings` flag prevents stale display during re-binding;
- LPF/HPF, Multi-FX On/Off, PingPong, Redux On/Off, ARP On/Off, Mode and Chord buttons are synchronised through parameter listeners,
  so they also follow **host automation**.

<Callout type="info" title="Tempo, length, volume">
  These controls are **not** re-bound: each has its own permanent attachment,
  car they belong to a specific row (or to the project for tempo).
</Callout>

## Hardware Graphics Acceleration & 120 FPS Fluidity

The UI incorporates advanced macOS rendering optimizations:
- **Native Opacity (`setOpaque(true)`)**: The root plugin editor is marked opaque to the macOS WindowServer. Window dragging, repositioning, and staging are handled via hardware GPU texture blit with zero CPU redraw overhead.
- **Unclipped Rendering (`setPaintingIsUnclipped`)**: The 192 step buttons and static controls bypass CoreGraphics clipping path calculations, ensuring a locked 60/120 Hz refresh rate.

## Component inspector

The plugin embeds **melatonin_inspector**. Two ways to open it:

- **⌘I** shortcut;
- the **Inspect** button, top-right.

The inspector lets you:

- select any component by clicking it;
- edit bounds, colours and margins live;
- browse the component tree and check `LookAndFeel`s;
- undo changes (wired to the processor's `undoManager`).

<Callout type="warn" title="Development tool">
  The inspector is compiled into every configuration. It has no impact on DSP but remains
  a debugging tool: disabling it for a public release means removing the
  `melatonin::Inspector` instance from the editor.
</Callout>

## “Hardware” theme

The UI does not use the default LookAndFeel:

- `MetuliferLookAndFeel` draws **hardware potentiometers** (groove, value arc,
  brushed metal body, needle) and **tactile buttons** with normal / hover / down states;
- the arc colour depends on the control type (amber for tempo/reverb, cyan for cutoff,
  blue for volume, violet for mix, sky for ADSR);
- step buttons show their number and visually group 4/4 downbeats.

See [UI and skinning](/en/docs/architecture/ui-skin) to replace these drawings with assets.
