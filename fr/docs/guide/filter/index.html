Guide utilisateur

Filtre (VCF)

Filtre passe-bas ou passe-haut TPT, cutoff 20 Hz – 20 kHz, par séquence.

Deux modes exclusifs

Le panneau VCF propose deux boutons mutuellement exclusifs :

BoutonParamètre seqN_filterComportement
LPF0passe-bas : laisse passer les fréquences sous le cutoff
HPF1passe-haut : laisse passer les fréquences au-dessus du cutoff

Cliquer sur le bouton déjà actif ne fait rien : le choix est toujours exactement l'un des deux.

Cutoff

ParamètreIDPlageDéfaut
CutoffseqN_cutoff20 Hz – 20 000 Hz (skew 1 kHz)1 000 Hz

Le cutoff est skewé autour de 1 kHz : la zone musicalement utile (100 Hz – 5 kHz) occupe la majorité de la course du potentiomètre.

Limite de Nyquist

La fréquence est bornée dans le code à min(cutoff, sampleRate × 0.49). À 44,1 kHz, le maximum effectif est donc ≈ 21,6 kHz ; à 96 kHz, le réglage de 20 kHz reste inchangé.

Implémentation

Le filtre est un State Variable TPT (juce::dsp::StateVariableTPTFilter<float>), utilisé en mode low-pass ou high-pass :

Caractéristiques :

  • topologie à variable d'état (TPT / SVF) → réponse stable même à cutoff élevé ;
  • 1 canal traité par voix (le signal est mono avant la reverb) ;
  • aucune résonance exposée pour l'instant (Q fixe) ;
  • le filtre est appliqué après la somme des deux VCO et avant le volume de séquence.

Ordre du signal

Le filtre est donc par voix, pas global : chaque séquence a son propre cutoff. Changer de séquence dans l'interface re-branche le knob Cutoff sur la nouvelle séquence.

Cible de modulation

cutoff fait partie des destinations acceptées par les câbles LFO. Voir LFO et câbles de modulation.

Synthé

Deux VCO, deux ADSR, mix en dB et gain staging — le synthé dédié à chaque séquence.

Multi-FX (Reverb, Delay, Redux)

Le module d'effets 3-en-1 par séquence avec onglets, témoins LED d'activation et traitement en série.
