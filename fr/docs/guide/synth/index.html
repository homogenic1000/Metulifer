Synthé

Deux VCO, deux ADSR, mix en dB et gain staging — le synthé dédié à chaque séquence.

Un synthé par séquence

Chaque séquence possède sa propre instance de Voice (Source/DSP/Voice). Conséquence importante : une séquence est monophonique — elle joue une note à la fois. Le plugin peut donc produire jusqu'à 6 notes simultanées, une par séquence.

Les deux VCO

ParamètreIDsPlageDéfaut
OctaveseqN_octave1, seqN_octave2−2 … +2 (levier, 5 crans)0
NoteseqN_note1, seqN_note20 … 11 (C … B)0 (C)
Forme d'ondeseqN_wave1, seqN_wave2Sine / Saw / Square / TriangleSaw

La fréquence se calcule sur une base C3 = 130,81 Hz :

Exemples : octave 0, note 0 → 130,81 Hz (C3) · octave +1, note 7 → 392,00 Hz (G4).

Anti-aliasing

Saw et Square sont générés avec polyBLEP : les transitions sont adoucies pour réduire fortement le repliement spectral, sans table d'ondes. Sine et Triangle sont calculés directement (pas de discontinuité).

Le levier d'octave

Le levier vertical (Source/UI/Lever) a 5 positions : +2, +1, 0, −1, −2. Il est relié au paramètre seqN_octaveN via un ParameterAttachment, donc :

  • il est automatisable par le DAW ;
  • il est annulable (undo) ;
  • sa valeur est sauvegardée avec l'état.

Le knob Note

12 crans, de C à B. Combiné au levier, il couvre 5 octaves × 12 demi-tons. Pas d'entrée MIDI pour l'instant : la hauteur vient uniquement de ces deux contrôles.

Les deux ADSR

Un ADSR par VCO : VCO1 → ADSR1, VCO2 → ADSR2.

ParamètreIDsPlageDéfaut
AttackseqN_a1, seqN_a20 – 5 000 ms (skew 500)5 ms
DecayseqN_d1, seqN_d20 – 5 000 ms (skew 500)200 ms
SustainseqN_s1, seqN_s20 – 100 %70 %
ReleaseseqN_r1, seqN_r20 – 5 000 ms (skew 500)300 ms

Chaque pas actif déclenche noteOn() sur la voix ; un pas inactif déclenche noteOff(). La queue de release continue donc de sonner après le pas — c'est ce qui donne le lié naturel entre deux pas rapprochés.

Mix et gain staging

ParamètreIDsPlageDéfaut
Mix VCO1seqN_mix1−60 … +6 dB0 dB
Mix VCO2seqN_mix2−60 … +6 dB0 dB
VolumeseqN_volume0 – 100 %80 %

Trois garde-fous ont été ajoutés pour éviter l'écrêtage :

  1. Somme normalisée : (VCO1 × mix1 + VCO2 × mix2) × 0.5 → deux oscillateurs à 0 dB somment à 0 dBFS, pas +6 dBFS.
  2. Mute franc : mix <= −59 dB ⇒ gain exactement 0.0.
  3. Volume à 0 : la voix coupe la sortie et réinitialise la reverb (silence parfait).

Enfin, le processBlock applique un headroom global ×0.5 puis une saturation douce tanh(), ce qui garantit un plafond analogique sans écrêtage dur du convertisseur.

Niveau de sortie

Si le signal sature encore dans le DAW, baisser d'abord seqN_volume, puis les mix, plutôt que de compenser sur le master du host.
