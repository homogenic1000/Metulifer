Référence des paramètres

Les 221 paramètres APVTS automatisables, leurs types, plages, identifiants et comportements.

Metulifer expose 221 paramètres automatisables gérés par un juce::AudioProcessorValueTreeState (APVTS) unique. Tous les paramètres sont thread-safe, consultables en lecture atomique par le thread audio sans allocation ni verrou.

Nomenclature

Les identifiants de paramètres suivent une convention uniforme :

  • Paramètres globaux : tempo
  • Paramètres de modulation : lfo<M>_<param> (où M vaut 1 ou 2)
  • Paramètres de voix / séquence : seq<N>_<param> (où N varie de 1 à 6)

Indexation 1-based pour l'utilisateur

Dans l'APVTS et dans le DAW, les séquences sont nommées de seq1 à seq6 et les LFO lfo1 et lfo2. En interne C++, les boucles parcourent les indices 0 à 5.

Ce qui n'est PAS dans l'APVTS

Certaines données dynamiques ne sont intentionnellement pas déclarées comme paramètres APVTS :

  1. Les masques de pas (32 pas × 6 séquences = 192 pas) : ils sont conservés dans un ValueTree séparé (steps) pour éviter d'inonder la fenêtre d'automation du DAW de centaines d'automations binaires.
  2. Les câbles de modulation virtuels : ils sont sauvegardés dans l'arbre mod.
  3. La Matrice de Modulation (Mod Matrix) : les 540 croisements bipolaires sont persistés dans l'arbre matrix (matrixTree) et synchronisés de manière lock-free via le tableau atomique modMatrix.
  4. Le compteur de pas courant et l'état de gate : mis à jour en temps réel à chaque cycle de restitution audio.
